App Mate

CIに登録する値をコピー

Tsumiki · 配布用の証明書（.p12）

変数名と値を1項目ずつCIの設定画面へ貼り付けます。App MateからCIへは送信しません。

変数名値操作
BUILD_CERTIFICATE_BASE64••••••••
P12_PASSWORD••••••••

Touch ID またはMacのパスワードで確認します。コピーした値は60秒後、内容が変わっていない場合だけ消去します。

値を含まないコマンド

pbpaste | gh secret set BUILD_CERTIFICATE_BASE64 --repo owner/repo

閉じる

画面状態の見本

保存・認証・削除は実行しない静的な見本です。

.p12パスワードを保存していない

P12_PASSWORD · 未保存

保存済みのパスワードがないためコピーできません。

ASC APIキーを選択した場合

ASC_KEY_ID / ASC_ISSUER_ID / ASC_KEY_P8_BASE64

各行に変数名、伏せた値、「認証してコピー」を表示します。

認証を取り消した場合

コピーしませんでした。値は伏せたままです。

コピー完了

コピーしました。60秒以内にCIへ貼り付けてください。

後からコピーした別の内容は消去しません。
