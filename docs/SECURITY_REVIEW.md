# ドキュメントの公開前確認

2026-10-17に、現在の作業ツリーにあるREADME、AGENTS.md、CLAUDE.md、CHANGELOG.md、docs配下のMarkdown・SVG、テスト用FixturesのREADME、およびGit管理外の監査レポート（Markdown・JSON）を確認した。文書の通読と、鍵・認証情報・識別子・個人情報に関する文字列検索を行った。

## 結果と対応

- 確認した文書に、実運用の秘密鍵、証明書の秘密鍵、Apple Accountのパスワード、セッションCookie、APIトークン、CI Secretsの値は見つからなかった。
- 旧READMEにあった開発者固有のApple Developer Team IDは、公開用の手順には不要なため削除した。Team IDは認証用の秘密ではないが、利用者自身のTeamを設定する説明に置き換えた。
- Bundle ID、署名プロファイル名、AppleのAPIパス、依存ライブラリのリビジョン、CI Secretsの変数名は、公開しても認証に使えない構成情報として残した。
- FixturesのREADMEにあるパスワードは、架空のテスト用`.p12`に対する既知の値であり、その用途を明記している。実運用には使わない。
- Git管理外の `CLAUDE-SECURITY-*` 監査レポートには、ローカルユーザー名を含む絶対パスがあった。レポート本文のパスを相対表記に直し、今後のローカル監査出力も誤って追加しないよう `.gitignore` に追加した。

## 確認範囲と制限

この確認は文書への秘密情報の混入を対象とする。Gitの過去のコミット、ブランチ・タグ、GitHubのActionsログ・Artifacts・Releases・Issues、画像内の文字、証明書・バックアップなどのバイナリの内容は確認していない。ソースコード全体の脆弱性監査や、秘密情報が存在しないことの保証ではない。

Team IDなどの構成情報はXcodeプロジェクトにも含まれる。文書からの削除によって、Git履歴や他のファイルから消えるわけではない。署名・保存先・既存データへの影響を避けるため、今回の変更ではプロジェクトの識別子を変更していない。
