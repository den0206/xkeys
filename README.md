# App Mate

Apple開発者向けの鍵・証明書・プロビジョニングプロファイル管理アプリ。**macOS 26.0以降**に対応し、SwiftUIとSwiftDataで実装しています。データをこのMacに暗号化保存し、期限は一覧とDockバッジで確認します。Apple Developerへのログイン・所属チームの確認時に外部通信を行います。iCloud同期・自動起動は行いません。

Apple Developer認証には[XcodesLoginKit](https://github.com/XcodesOrg/XcodesLoginKit)を使用します。信頼済み端末・SMSの確認コードに対応します。フェデレーション認証とセキュリティキーは今回の対象外です。Team IDの手入力はありません。

ログインセッションはこのMac専用のKeychain項目に保存し、再起動・画面ロック・スリープ後も再利用します。Apple Accountのパスワードや確認コードは保存しません。「設定 → セキュリティ → Apple Developer → 接続を解除」で削除できます。セッションの期限切れ時には再ログインが必要です。

未登録Team IDを含むバックアップは、すべての対象チームへの所属確認が必要です。脱退などで確認できない場合は復元できません。登録済みTeamだけならオフラインで復元できます。証明書・プロファイルのオンライン取り込みは後続リリースの対象です。

## 起動

### VS Code / Cursor

1. リポジトリを開き、推奨拡張機能 **CodeLLDB** をインストールする。
2. 「実行とデバッグ」で **Run App Mate Debug.app** を選び、**F5** を押す。

ビルドだけなら **⇧⌘B**。通常ビルドの出力先は `.build/xcode/Build/Products/Debug/App Mate.app` です。

### Xcodeと署名

`AppMate.xcodeproj` を開き、scheme **AppMate**、実行先 **My Mac** で実行します。開発環境はXcode 27.0 / Swift 6.4です。

秘密情報の保管にはApple Development署名が必要です。別の開発環境では **Signing & Capabilities** で利用するTeamを選び、Keychain Sharingの専用グループが設定されていることを確認してください。アドホック署名では使えません。

F5で `No Account for Team` / `No profiles` が出る場合は、最初に次の設定を行ってください。

1. Xcode → **Settings → Accounts** で開発用Apple Accountを追加する。登録済みなら再認証する。
2. `AppMate.xcodeproj` を開き、ターゲット **AppMate → Signing & Capabilities** で **Automatically manage signing** を有効にし、利用できる **Team** を選ぶ。現在のAppMateターゲットの指定は `4KJFNVZ8R6`。テストを実行する場合は **AppMateTests** のTeamも合わせる。
3. Xcodeで **AppMate / My Mac** を一度ビルドし、署名エラーが解消してからF5を実行する。

F5のビルドはプロビジョニングプロファイルの自動更新を許可しますが、Apple Accountの追加・再認証はXcodeで行う必要があります。

開発用Bundle IDは `com.example.AppMate.prototype`。Bundle IDや署名Teamを変更すると、既存のコンテナ・暗号鍵をそのまま利用できない場合があります。データの移行にはバックアップを使用してください。

## アプリとターゲット

本体・Share Extension・Widgetなど、Bundle IDが異なるターゲットを1つのアプリにまとめて管理できます。既存のAppはそのまま本体ターゲットになります。

- 追加：アプリの右クリック、または詳細の「…」から **ターゲットを追加…**。
- 登録済みのAppをまとめる：拡張側の **App・ターゲットを編集… → 所属アプリ** で本体を選んで保存。「独立したアプリ（本体）」で解除できます。
- 本体を選ぶと配下の資格情報をまとめて表示。上部の「ターゲット」で絞り込み、サイドバーの拡張を選ぶとその拡張だけ表示します。証明書・.p8は引き続きTeamで共有します。
- プロファイル取り込み：一致するBundle IDのターゲットを選択します。未登録なら **このアプリにターゲットを追加…** から登録できます。Bundle IDが似ているだけでは自動でグループ化しません。
- 本体の削除は配下のターゲットも対象です。アプリを選んでバックアップすると、配下のターゲットも含みます。

## 主な操作

| 操作 | 使い方 |
| --- | --- |
| 登録・編集 | Apple Developerにログインして所属Teamを選択し、Appの名前・Bundle ID・プラットフォームを追加。サイドバーの「登録済みチームを管理…」から全チームの名前・Team IDを確認し、編集・削除。チーム名横の「…」からも操作可能 |
| 取り込み | チームの「鍵・証明書」またはAppを選び「ファイルを追加」。鍵・証明書はチーム、プロファイルは対象Appに保管 |
| .p12 | 選択後にだけパスワード欄を表示。パスワードの暗号化保存は任意 |
| .p8 | 用途とKey IDを入力。App Store Connect APIの場合はIssuer IDも入力 |
| 更新 | 「既存の資格情報を置き換える」で旧→新と保管先を確認。旧ファイルは保持 |
| 詳細 | 元形式で書き出し、暗号化メモ、手動失効、保存済みパスワードの表示、CI用コピー |
| 削除・復元 | 鍵・ファイルは行を右クリック→「削除…」、複数まとめて削除する場合は一覧右上の「…」→「鍵・ファイルを一括削除…」でチェックして削除。Appは選択後、メイン画面右上の「…」→「アプリを削除…」。「最近削除した項目」で復元・完全削除。30日経過後は次回起動・認証時に整理 |
| バックアップ | 上部の「バックアップ」メニューで未バックアップ件数・前回日時を確認し、「今すぐバックアップ…」から書き出し。全体またはAppを選択でき、初期値はパスワード保護あり |
| 復元 | 未登録Team IDがある場合はApple Developerで所属を確認し、差分と競合を確認してマージ。全体置き換えでは現在の全データの事前退避が必須（データが空で設定も初期値なら不要） |
| 検索 | 全Team・Appのメタデータを複数語で検索。種別フィルターと併用可能。⌘Fで検索欄へ移動 |
| 設定 | Dockバッジ、CIテンプレートを変更して保存 |

証明書・秘密鍵はチームの一覧で保管し、プロファイルはApp専用です。App画面からチームの一覧へ移動できます。チームの鍵・証明書は種類と用途で絞り込めます。実際に利用するAppの記録や、Apple側の所属確認はチーム登録・未登録チームのバックアップ復元時に行います。Appを削除しても共有鍵は残ります。元ファイルは変更・削除しません。Apple側の失効状態は照会しません。

秘密情報の操作はTouch IDまたはMacのパスワードで毎回認証します。バックアップは元ファイル・メモ・保存済みパスワード等を含むため、安全な場所で保管してください。パスワードなしの書き出しには再確認が必要です。
