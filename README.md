# App Mate

Apple開発者向けの鍵・証明書・プロビジョニングプロファイル管理アプリ。**macOS 26.0以降**に対応し、SwiftUIとSwiftDataで実装しています。データをこのMacに暗号化保存し、期限をローカル通知します。外部通信・iCloud同期・自動起動は行いません。

## 起動

### VS Code / Cursor

1. リポジトリを開き、推奨拡張機能 **CodeLLDB** をインストールする。
2. 「実行とデバッグ」で **Run App Mate Debug.app** を選び、**F5** を押す。

ビルドだけなら **⇧⌘B**。通常ビルドの出力先は `.build/xcode/Build/Products/Debug/App Mate.app` です。

### Xcodeと署名

`AppMate.xcodeproj` を開き、scheme **AppMate**、実行先 **My Mac** で実行します。開発環境はXcode 27.0 / Swift 6.4です。

秘密情報の保管にはApple Development署名が必要です。別の開発環境では **Signing & Capabilities** で利用するTeamを選び、Keychain Sharingの専用グループが設定されていることを確認してください。アドホック署名では使えません。

開発用Bundle IDは `com.example.AppMate.prototype`。Bundle IDや署名Teamを変更すると、既存のコンテナ・暗号鍵をそのまま利用できない場合があります。データの移行にはバックアップを使用してください。

## 主な操作

| 操作 | 使い方 |
| --- | --- |
| 登録・編集 | Teamを登録し、Appの名前・Bundle ID・プラットフォームを追加。Appの右クリックまたはTeam名から編集 |
| 取り込み | Appを選び「ファイルを追加」。複数ファイル・フォルダを指定し、1件ずつ内容と所属を確認 |
| .p12 | 選択後にだけパスワード欄を表示。パスワードの暗号化保存は任意 |
| .p8 | 用途とKey IDを入力。App Store Connect APIの場合はIssuer IDも入力 |
| 更新 | 「既存の資格情報を置き換える」で旧→新と共有先を確認。旧ファイルは保持 |
| 詳細 | 元形式で書き出し、暗号化メモ、手動失効、保存済みパスワードの表示、CI用コピー |
| 削除・復元 | 「最近削除した項目」で復元・完全削除。30日経過後は次回起動・認証時に整理 |
| バックアップ | 全体またはAppを選んで書き出し。初期値はパスワード保護あり |
| 復元 | 差分と競合を確認してマージ。全体置き換えでは現在の全データの事前退避が必須 |
| 検索 | 全Team・Appのメタデータを複数語で検索。種別フィルターと併用可能。⌘Fで検索欄へ移動 |
| 設定 | 通知の許可・日数、Dockバッジ、メニューバー、CIテンプレートを変更して保存 |

証明書・秘密鍵は同じTeamの全Appで共有し、プロファイルはApp専用です。Appを削除しても共有鍵は残ります。元ファイルは変更・削除しません。Apple側の失効状態は照会しません。

秘密情報の操作はTouch IDまたはMacのパスワードで毎回認証します。バックアップは元ファイル・メモ・保存済みパスワード等を含むため、安全な場所で保管してください。パスワードなしの書き出しには再確認が必要です。
